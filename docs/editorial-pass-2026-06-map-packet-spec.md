## Why a raster base + overlay (not a redrawn map)

A genuine 16th–17th-century engraving gives the scholarly, period feel the article wants, with zero copyright risk. The clusters ride on top as an original density layer (our oxblood-on-parchment rendering — nothing of Geneanet's). The base is a static raster; the overlay is positioned by pinning to towns visible on that specific scan (old maps have idiosyncratic projections, so cluster centres are placed by eye against Gent / Cassel / Brussel, not by lat-long math).
